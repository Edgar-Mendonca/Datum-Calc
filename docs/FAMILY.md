# The Datum family

Datum Calc follows the family design guide, which lives in the hub repository:
**[Edgar-Mendonca/Datum › FAMILY.md](https://github.com/Edgar-Mendonca/Datum/blob/HEAD/FAMILY.md)**.

Section numbers are stable ("FAMILY §3" is colour everywhere). Calc's own choices within it:
- Accent **Amber**: `--blue #A8650F`, hover `#8E550C`, sky `#F2CF8E`, pale `#FBF2E2`, sel `#F6E7CB`, sel2 `#EBD09E`, dark `#F0B450`, File sidebar (dark) `#5A3A0C`.
- Logo: the family tile in amber; a square-root sign over an "x", an "=" below, and the amber diamond (`docs/brand/datum-calc-icon.svg`).
- Files `.dcalc` (JSON, versioned); identifier `com.edgarmendonca.datumcalc`; installer `DatumCalc-x.y.z-setup.exe` + `SHA256SUMS.txt`.
- Windows publisher **Datum** (FAMILY §9); the copyright stays "© 2026 Edgar Mendonca".
